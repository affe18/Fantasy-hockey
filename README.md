# RinkIQ — Fantasy Hockey Intelligence

A responsive, interactive concept dashboard for fantasy hockey managers. The static prototype brings roster projections, player trends, schedule advantages, teammate impact, news alerts, and entry points for trade, waiver, draft, and player analysis into one view.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Prototype notes

- Dashboard figures and news are illustrative sample data, not live NHL data.
- Interactive analyzers demonstrate the product flow using client-side sample recommendations.
- Google Fonts are loaded remotely; system fallbacks are provided.

## Next steps

Connect an NHL statistics and news provider, add a league/import integration, and replace the sample scoring projections with configurable scoring-aware models.
